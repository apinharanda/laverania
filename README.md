**Protein Evolution Explorer for *Plasmodium* (PEEP)**

This repository contains the code and analysis workflow used to:
* construct orthogroups and comparative sequence alignments;
* estimate gene-level and site-level divergence;
* calculate *P. falciparum* diversity;
* integrate diversity and divergence into gene- and site-level datasets;
* compare diversity with divergence genome-wide;
* examine intervention-relevant proteins, including vaccine, diagnostic, and drug targets;
* generate the manuscript figures; and
* build the PEEP Shiny application and its precomputed deployment data.
